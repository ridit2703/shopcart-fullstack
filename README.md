# Shopcart 🛒

🚧 **Project Status:** Work in Progress

ShopCart is a full-stack e-commerce web application built using the MERN stack. The project is currently under development, and new features are being added regularly.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS

## Project Structure

shopcart/
├── frontend/
└── backend/

## Features

- ✅ User Registration & Login
- ✅ Product Listing
- ✅ Product Details
- ✅ Shopping Cart (In Progress)
- ✅ JWT Authentication & Authorization
- ✅ Product Categories
- ✅ Product Search
- ✅ Wishlist
- ✅ Shopping Cart
